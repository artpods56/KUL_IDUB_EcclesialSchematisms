Mapping to the app: the animated element is the same shellStack/shellFrame that carries shellStackPickedUp/shellFramePickedUp today; "remeasure" = the existing updateNodeInternals(id) layout-effect call (move it to transitionend/animation finish for B–E). The interrupt guard for B/E is the first position change / onNodeDragStart after selection: add a no-transition class, snap to the lifted transform, remeasure now. The two lift tiers (−2px active, −8px dragging) become a new active style tier on the same elements, with the plate at reduced opacity while merely active. Recommendation: compare B and E in slow-mo; pick D if any edge drift is unacceptable. Respect prefers-reduced-motion by collapsing all durations to 0 (the app already gates shadow transitions the same way).

Ship note (option C, implemented): the app upgrades the deferred remeasure shown here to a bounded rAF loop that remeasures handle bounds every frame while the spring runs (stopped on transitionend, 260ms fallback), so connected edges glide with the handles and never jump at settle. Real drags still snap the lift and remeasure once, immediately. Same per-frame cost class as dragging the node itself — reads only, no layout writes.
